# 慢慢来｜家庭词语练习（完全离线版）

这是供家庭辅助练习使用的中文词语认知训练网站。它不提供诊断、医学评分或疗效判断。

## 日常使用

在本项目文件夹中双击 `启动离线练习.bat`，浏览器会打开练习页面。启动和练习都不需要互联网。

- 词库、内置图片和页面程序都保存在本机。
- 家属拍摄的照片、录音和练习记录保存在当前浏览器中。
- “家属管理 → 备份与恢复”可以下载完整备份；更换电脑或清理浏览器前请先备份。
- 如果没有家属录音，会使用设备已安装的中文系统语音。为了保证所有设备都能断网播报，建议为常练词汇录制家人的声音。
- 本地数据不会自动同步到其他手机、平板或电脑。

## 复制到另一台 Windows 电脑

复制整个项目文件夹。目标电脑需要安装 Node.js，然后双击 `启动离线练习.bat`。首次在新浏览器中打开时，词库会自动建立；原有照片、录音和记录可通过备份文件恢复。
